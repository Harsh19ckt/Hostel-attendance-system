 Project Statement: Hostel Attendance System

  Problem Statement
Keeping track of hostel attendance manually using paper sheets or messy lists is a huge pain. 
It's super easy to misplace records, waste time, or make mistakes when updating who is actually around. We needed a simple, reliable way to handle student attendance digitally right from the command line without any complicated setup.

  Scope of the Project
This project is a lightweight, multi-file Python application built to handle basic attendance tasks. 
What it does: "It lets you register new students, update their daily status (Present/Absent), and print out clean attendance summaries".
What it doesn't do: "It doesn't use a heavy external database or a web GUI, everything runs locally in the terminal using Python data structures and modular files".

  Target Users
1.Hostel wardens or caretakers who want a quick, no-nonsense tool to log daily attendance.
2.Students or developers looking for a clean example of a modular Python command-line app.

  High-Level Features
Student Management: Safely add new students with built-in checks to prevent duplicate entries.
Attendance Tracking: Easily flip a student's status between Present and Absent with instant input validation.
Report Generation: Print out a neatly formatted list showing everyone's current status.
