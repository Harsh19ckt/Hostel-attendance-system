# Hostel Attendance System

Hey! This is just a simple Python project I put together to make taking hostel attendance way easier than messing with paper sheets or messy spreadsheets. It runs right in your terminal, it lets you add students, and update their status between present and absent, and print out a clean list of who's around.

What it can do:
Add new people: Easily register new students into the list.

Update status: Quickly change someone from present to absent (or vice versa) if things change.

View everyone: Print out a neat, formatted list of the whole hostel's attendance right on your screen.

How to run it:
download this repo to your computer.

Open up your terminal inside the project folder.

Run the main file with this command:

Bash
python main.py
Just follow the menu options on your screen (1 to view, 2 to update, 3 to add someone, and 4 to quit).

How to test it out:
Try adding a student whose name is already there to see how it handles duplicates.

Try typing a random word instead of "Present" or "Absent" when updating to test out the error messages.
